# CosmoVision — Controls

## Mouse / touch

| Action | Input |
| --- | --- |
| Select object | Click (≤ 6 px travel) |
| Focus object | Double-click |
| Orbit camera | Drag |
| Pan (overview only) | Shift-drag or right-drag |
| Zoom | Mouse wheel / pinch |
| Deselect | Click empty space |

## Keyboard

| Key | Action |
| --- | --- |
| `/` or `Ctrl/Cmd + K` | Open search |
| `Space` | Play / pause simulation |
| `Esc` | Close panel, cancel search, exit focus |
| `Home` | Galaxy overview |
| `Backspace` | Navigation history — back |
| `+` / `−` | Zoom in / out |
| `R` | Reset camera orientation |
| `L` | Toggle object labels |
| `T` | Toggle orbit trails |
| `←` `→` `↑` `↓` | Orbit the camera |

Search overlay: `↑` `↓` navigate results, `Enter` focuses the highlighted
object, `Esc` closes.

## UI

- **Top bar** — simulation status, WebGL status, search, panels (Info, Galaxy,
  Compare, Journal, Tours, Perf, Settings), help.
- **Left rail** — category filters (Galaxy, Star system, Star, Planet, Moon,
  Asteroid field).
- **Bottom bar** — breadcrumbs, play/pause + speed + reset + trails + sim date,
  back/home/exit-focus/zoom/reset.
- **Info panel** — facts with precision labels (science mode), sources, related
  objects, journal notes, focus/compare/bookmark actions.
